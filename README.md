# 🏆 ML-ядро платформы для ФСП (Лидеры цифровой трансформации 2026)

Микросервис на базе FastAPI и GigaChat API, реализующий интеллектуальный пайплайн оценки и подбора IT-специалистов для Федерации спортивного программирования. 

## 1. Архитектура 🏗️
Проект построен по микросервисной архитектуре (Backend-Driven ML). 
* **Core:** Python 3.9+, FastAPI, Pydantic.
* **LLM-Интеграция:** GigaChat API (модели `GigaChat-2-Pro` и `GigaChat-2-Max`). Выбор российских моделей обусловлен требованиями 152-ФЗ о локализации ПДн. Инференс происходит по API, что позволяет разворачивать проект на серверах без GPU (CPU-only).
* **База знаний (Инварианты):** Внутреннее хранилище `invariants.py` с математическим ядром задач, исключающее галлюцинации LLM.
* **Изоляция (Sandbox):** Модуль `subprocess` (в MVP) / изолированный Docker-контейнер (в Prod) для безопасного запуска пользовательского кода.

## 2. Механика тестирования и грейдирования 🎯
Согласно правилам ФСП, грейд участнику присваивается **исключительно по результатам тестирования**, а не на основе заявленного опыта в резюме. Наша система реализует 3-этапную защиту:

1. **Семантическая маскировка (Анти-чит):** Нейросеть генерирует уникальные текстовые легенды (сюжеты) на базе жестких математических шаблонов (Junior, Middle, Senior). Задачи невозможно нагуглить или списать друг у друга, при этом алгоритмическая сложность остается абсолютно идентичной для всех участников.
2. **AST-Анализатор (Статический анализ):** Модуль `ast` парсит синтаксическое дерево Python-кода кандидата до его запуска, выявляя вложенность циклов. Это позволяет оценивать асимптотическую сложность алгоритма (Big-O: $O(1), O(log n), O(n), O(n^2)$).
3. **Sandbox + Hidden Tests (Динамический анализ):** Код выполняется в изолированной среде с жестким Time Limit. В код передаются скрытые тесты (Edge cases) из `invariants.py`. 
*Итоговый балл (0-100) формируется взвешенно на основе пройденных тестов и оптимальности AST-дерева.*

## 3. Механика подбора и логика категоризации 🤝
Платформа реализует **объяснимый подбор** (Explainable AI Matching) и адресное приглашение.
Алгоритм категоризации использует GigaChat-Pro с низкой температурой (0.2) для строгого аналитического сравнения JSON-профиля кандидата с текстом вакансии работодателя.
На выходе формируется:
* Процент совместимости (Match Percentage).
* Текстовое обоснование для работодателя (почему кандидат подходит или нет).
* Автоматически выделенные сильные (Pros) и слабые (Cons) стороны.

## 5. Схемы предполагаемой интеграции с FSP / FSP ID 🔐
Так как API боевого Keycloak ФСП закрыто для участников, мы заложили архитектуру имитации единой точки входа (SSO):
1. **Авторизация:** Клиент (React) редиректит пользователя на форму входа FSP ID (в MVP имитируется заглушкой).
2. **OAuth 2.0 / OIDC:** После успешного входа Keycloak (FSP ID) возвращает `Authorization Code`, который фронтенд меняет на нашем бэкенде на `Access Token` и `ID Token`.
3. **Обогащение профиля:** По токену бэкенд «запрашивает» (в MVP берет из мок-базы) подтвержденные спортивные достижения участника (ранги, хакатоны), которые влияют на ранжирование в выдаче.

## 6. Описание API 🔌
Базовый URL: `http://localhost:8000`

* **`POST /api/cv/parse`** — Извлечение навыков, грейда и стека из сырого текста резюме.
* **`GET /api/tasks/generate-tournament?theme={theme}`** — Выдача сета из 3-х уникальных задач (Junior, Middle, Senior) в едином сеттинге.
* **`POST /api/grader/submit`** — Отправка кода на проверку (Sandbox + AST). Возвращает пройденные тесты и итоговый балл.
* **`POST /api/match`** — Умное сравнение профиля и вакансии. Возвращает `% совместимости` и объяснение.

*(Интерактивная Swagger-документация доступна по адресу `/docs` после запуска сервера).*

## 8. Инструкция по сборке и запуску 🚀

**Вариант 1: Локальный запуск (Разработка)**
1. Клонировать репозиторий: `git clone <url_вашего_репо>`
2. Создать виртуальное окружение: `python3 -m venv venv && source venv/bin/activate`
3. Установить зависимости: `pip install -r requirements.txt`
4. В файле `config.py` вставить токен GigaChat: `GIGA_TOKEN = "ваш_токен"`
5. Запустить сервер: `uvicorn main:app --host 0.0.0.0 --port 8000`

**Вариант 2: Изолированный запуск через Docker (Для проверки Жюри)**
1. Убедиться, что Docker установлен на сервере проверки.
2. Собрать образ: `docker build -t fsp-ml-core .`
3. Запустить контейнер: `docker run -d -p 8000:8000 --name fsp_backend fsp-ml-core`
4. Платформа доступна по адресу `http://localhost:8000/docs`.
