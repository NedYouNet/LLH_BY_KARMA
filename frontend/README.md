# Интерфейс ФСП Таланты

Общий запуск из корня — `docker compose up -d --build`, сайт localhost:5173.
Для разработки остановите Docker-сервис frontend, в этой папке выполните `npm ci` и `npm run dev`. API пересылается Vite на localhost:8000; другой адрес задаётся BACKEND_URL в .env.local.

`npm run build` создаёт dist, `npm run lint` проверяет код. В Git остаются исходники и package-lock.json; node_modules, dist и .env.local не коммитятся.

Тестирование: три Python-задачи 20/30/50, предварительные проверки через backend, по десять на задачу. Новая попытка открывает пустой редактор; черновик введённого кода сохраняется. Тема переключается в шапке; редактор Monaco остаётся тёмным.
