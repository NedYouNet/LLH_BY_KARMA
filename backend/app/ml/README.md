# Встроенный ML

Актуальное описание — [docs/11_ml.md](../../../docs/11_ml.md), передача разработчику — [docs/handoff/ml.txt](../../../docs/handoff/ml.txt).

`resume.py` — опциональный GigaChat-разбор текста PDF; `matching.py` — локальная текстовая похожесть. Банк задач лежит в `app/testing_bank/bank.py`, генерация и баллы — в `app/services/testing_engine.py`. Отдельный сервис 8001 не нужен.

Ключ: переменная окружения GIGA_TOKEN. При отсутствии ключа разбор резюме использует fallback; контест работает без LLM. Задания заранее описаны текстом, данные создаются make(rng). Не все шаблоны полностью параметризованы.

Проверки из backend/: `python -m pytest -q`, `python -m scripts.verify_hybrid_testing`. После изменений банка дополняйте эталоны и тесты. Секреты, реальные контакты и .env не коммитить.
