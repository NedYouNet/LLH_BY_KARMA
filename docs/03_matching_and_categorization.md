# Подбор и категоризация

Категория — направление и грейд. Подтверждённая категория берётся из завершённого теста; без теста используется заявленная категория с пометкой и понижающим множителем. Работодатель фильтрует выдачу и получает балл соответствия, причины и вклад факторов. Избранное хранится отдельно от оценки соответствия.

Текущая формула находится в `backend/app/services/matching_engine.py`; настройки — в `app/core/config.py`. Веса по умолчанию: тест 0.35, ФСП 0.15, навыки 0.35, текст 0.05, активность 0.10. Компоненты без применимого сигнала исключаются, оставшиеся веса нормируются. Неподтверждённый грейд получает множитель 0.6; соседний с целевым — 0.7; отличие на две и более ступени — 0.5.

При `app/ml/matching.py: ENABLED=True` текстовый сигнал — доля токенов запроса, найденных в тексте кандидата. Это локальный расчёт без LLM и без сетевого запроса на каждого кандидата. TF-IDF остаётся альтернативной веткой движка. `breakdown`, `reasons`, `matched_skills` и отсутствующие навыки объясняют расчёт интерфейсу.

Веса из автономного прототипа `Data_Scientist` не перенесены автоматически: его формула и API отличаются. Реальные профили берутся из базы основного приложения, а не из CSV. Качество ранжирования на размеченной выборке независимого оценщика в этой сборке ещё не подтверждено.
