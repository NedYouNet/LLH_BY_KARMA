# ATS и разрешение контактов

В dev встроен тестовый приёмник ATS. Под работодателем сохраните `webhook_url` = `http://localhost:8000/api/mock-ats/webhook` через `PUT /api/employer/integrations/ats`. Проверка: `POST /api/employer/integrations/ats/test`, ожидается `ok: true`. `GET /api/mock-ats/events` возвращает последние события; смотрите `signature_valid`.

Событие принятия приглашения — `invitation.accepted`. Это локальная демонстрация доставки, а не настройка реальной внешней ATS. В prod mock-приёмник выключен; для настоящей интеграции нужны адрес приёмника, проверка подписи и обработка повторной доставки на стороне ATS.

Кандидат управляет разрешением контактов. Работодатель видит данные только при действующем разрешении. Независимому тестировщику нужно проверить обе роли, отзыв разрешения и отсутствие контактов в закрытых API-ответах, а не только текст плашки на экране.
