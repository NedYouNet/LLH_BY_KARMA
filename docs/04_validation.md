# Проверки текущей сборки

Проверки выполнялись при подготовке сборки 10 октября 2026 года. Независимый тестировщик ещё не проводил итоговую проверку; она запланирована на 11 октября. Это отдельный этап, результаты которого следует добавить сюда после выполнения.

| Проверка | Результат |
|---|---|
| `python -m pytest -q` на SQLite | 169 тестов прошли; одно предупреждение устаревающего API зависимости Starlette/AnyIO |
| Покрытие банка | 60 шаблонов, 5 направлений, 4 грейда, 3 сложности |
| Эталонные алгоритмы | 20 сочетаний направления/грейда: эталонные алгоритмы прошли все тесты, 100/100 |
| Сборка фронтенда | `npm ci`, `npm run lint` и `npm run build` прошли; Monaco включён в локальную сборку |
| Docker Compose и PostgreSQL на машине сборки | Не запускались: Docker здесь недоступен |
| Реальный GigaChat и настоящий FSP ID | Не подтверждены этим прогоном; тесты не используют реальные ключи |
| Независимые сценарии UI и реальная ATS | Предстоят |

Автотесты проверяют API и права доступа, тестирование, баллы, сохранение проверок, контакты, ФСП, ATS и контракты ML. Проверка эталонных решений выполняет реальные Python-функции на тестах банка. Она подтверждает согласованность банка с выбранными эталонами, а не полноту всех граничных случаев.

## Воспроизведение

Из `backend/` с Python 3.12:

```shell
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m scripts.verify_hybrid_testing
```

GitHub Actions дополнительно запускает тесты на PostgreSQL и цикл миграций. Статус CI следует проверить у опубликованного коммита; локальный SQLite-прогон не заменяет PostgreSQL-прогон.

`scripts.evaluate` моделирует кандидатов и синтетические пары для исследовательской оценки. Его результаты не равны проверке реальных кандидатов или независимой оценке качества ML. Старые цифры про тысячи вариантов, точность, утечки и нагрузку не переносятся в отчёт без актуального воспроизводимого прогона.

Перечень оставшихся сценариев и форма регистрации дефекта: [QA_CHECKLIST.md](QA_CHECKLIST.md). Дефект должен содержать роль, шаги, ожидаемый и фактический результат, HTTP-ответ и `health.build`.

Сборщик предупреждает о размере лениво загружаемого Monaco-чанка (~2.7 MB до gzip, ~699 kB gzip). Это локальная зависимость редактора; остальной интерфейс загружается отдельным меньшим чанком. Предупреждение не является ошибкой сборки.
