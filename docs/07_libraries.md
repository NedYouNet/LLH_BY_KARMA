## Инфраструктура (Docker)

| Компонент | Образ / версия | Роль |
|---|---|---|
| Бэкенд | `python:3.12-slim` + шрифты DejaVu (кириллица в PDF) | API |
| База данных | `postgres:16-alpine` | Хранение данных |
| Демо-почта | `axllent/mailpit` | Ловит письма подтверждения на стенде (веб: порт 8025) |
| Фронтенд (сборка) | `node:22-alpine` | `npm ci && npm run build` |
| Фронтенд (отдача) | `nginx:1.27-alpine` | Статика + прокси `/api` на бэкенд |

## Фронтенд — `frontend/package.json`

React 19, Vite 8, Tailwind CSS 4, Monaco Editor (`@monaco-editor/react` 4.7), Pyodide в Web Worker
(запуск кода кандидата на видимых примерах в браузере). Точные версии — в `frontend/package.json`
и `frontend/package-lock.json` (раздел дополняет фронтенд-разработчик).

## ML-часть — `backend/app/ml/`

Модели, библиотеки и их версии описывает ML-разработчик команды, включая **какие LLM используются, как и зачем**.
Это обязательное требование организаторов; ожидаются российские модели из-за трансграничной передачи ПДн.

## Внешние сервисы

Обязательных нет: стенд полностью автономен. FSP ID и реестр ФСП имитируются внутри бэкенда, почта ловится
Mailpit. Видеокарта не нужна.
